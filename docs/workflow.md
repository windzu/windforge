# 设计、打印与发布流程

这个流程用于保留必要信息，让 Wind 与 AI 能接着上一次进度继续工作。小作品可以直接在模型 README 中完成全部记录。

## 1. 明确想法

先说明模型用来解决什么问题或表达什么创意，再记录关键尺寸、使用场景、装配对象和设计偏好。

依赖现有物品尺寸的设计，应先取得测量数据。影响设计的未知条件保留为待确认；AI 提出的假设应写清楚。

## 2. 建模与导出

- 建立模型目录，并复制模型说明模板。
- 保存可编辑源文件，记录工具及必要版本信息、单位、关键参数和导出方法。
- 将用于打印的 STL 或 3MF 等文件放入 `exports/`，说明对应版本。
- 保存能展示外观、尺寸或结构的预览图。
- 对几何与打印条件做针对性检查，记录结果和待验证问题。

模型版本从 `v0.1` 等初始版本开始即可。重要变更说明具体变化及原因；Git 提交保留设计历史，模型版本用于对应打印和发布文件。

## 3. 打印验证与迭代

打印前记录计划使用的设备、材料、方向、层高、壁数、填充和支撑等参数。切片后的预估时间及耗材与实际测量分开记录。

打印后由 Wind 提供结果、实拍和必要测量，AI 协助整理并提出下一轮改动。重点关注使用效果、尺寸适配、装配、表面质量和结构表现。

失败也保留记录：原本预期什么、实际发生什么、现有证据支持哪些原因、下一次改变哪些条件。一次迭代尽量围绕明确问题推进。

切片项目可以保存到 `print/`。如果导出模型与切片工程都使用 3MF，应通过名称及 README 说明区分用途。

## 4. 准备 MakerWorld 发布

作品达到预期后，整理以下材料：

- 可打印模型及适用的打印配置；文件对应到验证过的版本。
- 作品名称、用途、特点和必要的尺寸说明。
- 清晰的封面、模型预览、实拍，以及需要时的装配图。
- 已验证的打印参数、装配步骤和使用说明。
- 由 Wind 确定的许可信息。

AI 可以协助准备和检查材料。是否发布、以什么版本发布由 Wind 决定；实际发布后，在模型 README 和根目录模型索引中补齐链接。

## 状态约定

| 状态 | 含义 |
| --- | --- |
| 构思中 | 正在明确用途、需求和约束 |
| 设计中 | 正在建模或调整结构 |
| 待打印验证 | 已有导出模型，仍需实物验证 |
| 打印已验证 | 已有实际打印结果，说明验证范围和对应版本 |
| 已发布 | 已在 MakerWorld 发布，保存链接和对应版本 |

作品可以回到设计阶段继续改进。发布记录与新版本进度分别保留，避免把旧版本的验证结果套用到新版本。
